### Инфраструктура

* **IP:** чистые VPN (AdGuard, NordVPN, Windscribe) или статические / мобильные прокси (Proxys.io, Proxy-Seller и аналоги).
* На мобиле для прокси удобны Tun2Socks и похожие клиенты.
* **Регистрация:**
  * Email — только с максимально чистым IP (иначе риск долгого лока).
  * Телефон — устойчивее; SMS: SmsHub, SmsActivate.
{% endstep %}

### Стратегия контента (Reels)

Каждый ролик:

1. Сильный [хук](khuki.md) в первые секунды.
2. Описание **выше** хештегов + CTA.
3. Релевантные теги (финансы / бизнес / crypto-adjacent — без прямого триггера, если аккаунт «белый»).
{% endstep %}

### Методы работы

**Аккаунты с историей (180+ дней):**

* Лёгкий прогрев: 5–7 тематических подписок → пауза ~20 мин → постинг.
* Массовый запуск пула с одним крео повышает шанс попасть в рекомендации.

**Самореги:**

1. Регистрация на одном устройстве.
2. Вход с другого чистого устройства.
3. Пауза ~24 ч → пост → ещё 24 ч → отбор живых аккаунтов.
{% endstep %}

### Воронка «кодовое слово + Direct»

1. В ролике: «напиши в Direct слово **BONUS** / своё кодовое».
2. Закрепленный комментарий дублирует условие.
3. В Direct — ссылка на оффер / канал (вручную на старте, автоответ — при масштабе).

Плюсы: фильтрация аудитории, рост вовлечённости, меньше прямых ссылок в описании.
{% endstep %}
