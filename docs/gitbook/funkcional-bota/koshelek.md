# Профиль и кошелёк

Разделы бота для участника команды.

### Профиль

В профиле отображаются ваши данные, настройки и связанные действия (включая анонимность в топах — если доступно в вашей сборке бота).

### Кошелёк

Кошелёк показывает доступный баланс для вывода.

{% stepper %}
{% step %}
Откройте **Кошелёк** в главном меню.
{% endstep %}

{% step %}
Проверьте доступную сумму. Минимальный порог вывода задаётся проектом (по умолчанию ориентир — от **$10**, актуальное значение смотрите в боте).
{% endstep %}

{% step %}
Создайте заявку на вывод и выберите метод получения.
{% endstep %}

{% step %}
Дождитесь модерации. При необходимости администрация запросит дополнительные данные / ссылку на выплату.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Не создавайте дублирующие заявки. Статус отслеживайте в боте и канале выплат (доступ через **О проекте**).
{% endhint %}
