# Профиты и выплаты

Как устроена экономика воркера в Garbona.

### Процент

Глобальный процент воркера задаётся администрацией и отображается в **О проекте**. Индивидуальный процент может отличаться — его видит админ в карточке участника.

### Профиты

* Начисление профитов делает администрация.
* В боте доступны сводки и история (раздел профитов / кошелёк — по актуальному меню).
* При начислении бот присылает уведомление с суммой и вашей долей.

### Выплаты

1. Накопленная доля попадает в доступный баланс.
2. Вы оформляете вывод через кошелёк.
3. Модерация подтверждает или отклоняет заявку.
4. Канал выплат (для команды) отражает публичную часть процесса — без нарушения [правил](../proekt/pravila.md).

{% hint style="success" %}
Прозрачность = меньше споров. Если сумма или статус непонятны — пишите [@karma_ceo](https://t.me/karma_ceo) в личку, не в общий чат.
{% endhint %}

### О проекте (цифры)

В меню **О проекте** можно увидеть:

* дату открытия команды;
* сумму и количество профитов;
* актуальный процент выплат воркеру.
