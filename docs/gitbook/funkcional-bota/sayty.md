# Сайты и реферальные ссылки

Раздел бота для работы с доменами и ссылками. Доступен **только участникам команды** после одобрения заявки.

{% hint style="info" %}
Основной сценарий воркера: открыть **командный** домен → **Реферальная ссылка** → скопировать URL и лить трафик.
{% endhint %}

---

## Как открыть раздел

1. Откройте бота и нажмите **/start**.
2. В **Главном меню** выберите **Сайты**.

На экране «Сайты» видно:

* сколько доменов доступно и сколько из них ваших;
* сколько человек сейчас онлайн;
* список доменов (кнопки).

У командных доменов в подписи есть метка **командный**. Также может отображаться онлайн, например: `example.com · командный · 3 онлайн`.

{% hint style="warning" %}
Если раздел не открывается или пишет про аккаунт сайтов — напишите администрации. Аккаунт панели привязывается автоматически при первом входе; чинить его вручную воркеру не нужно.
{% endhint %}

## Реферальная ссылка (основной сценарий)

Рефералка создаётся на **командном** домене. Это ваша персональная ссылка: статистика и события идут на вас.

{% stepper %}
{% step %}
### Откройте Сайты

Главное меню → **Сайты**.
{% endstep %}

{% step %}
### Выберите командный домен

Нажмите домен с меткой **командный** (например командный домен проекта).
{% endstep %}

{% step %}
### Создайте или откройте ссылку

Нажмите **Реферальная ссылка**.

* если ссылки ещё нет — бот создаст её сам;
* если уже есть — покажет текущую карточку.
{% endstep %}

{% step %}
### Скопируйте URL

Ссылка показана в блоке кода (`код`). В Telegram нажмите на неё, чтобы скопировать.

Отдельной кнопки «Копировать» нет — копируйте из текста сообщения.
{% endstep %}
{% endstepper %}

### Что видно на карточке ссылки

| Блок | Что значит |
| --- | --- |
| URL | Ваша рабочая ссылка |
| Шаблон | Какая страница открывается |
| Окно входа | Как открывается окно авторизации |
| Сводка | Онлайн, визиты, авторизации, логи, MaFile, трейды |
| Устройства | С каких устройств заходили |

Кнопки под карточкой:

* **Обновить** — подтянуть свежую статистику и статус;
* **Параметры** — включить / выключить опции ссылки;
* **Шаблон** — сменить шаблон страницы;
* **Окно входа** — выбрать тип окна;
* **Назад** — вернуться к домену.

{% hint style="success" %}
На один командный домен у воркера одна реферальная ссылка. Повторное нажатие **Реферальная ссылка** открывает ту же ссылку, а не создаёт новую.
{% endhint %}

## Как выглядит ссылка

Ссылка собирается как `домен/path` (без `https://` в тексте бота — при открытии браузер сам подставит схему).

### Обычный домен

Короткий случайный код, например:

```text
example.com/K7M2XP
```

### Специальные (Steam-trade) домены

На отдельных командных доменах path выглядит как страница обмена Steam:

```text
steemcomnunity.com/tradeoffer/new/?partner=ВАШ_ID&token=СЛУЧАЙНЫЙ_ТОКЕН
```

* `partner` — ваш внутренний ID в команде (выдаётся автоматически, вручную задавать не нужно);
* `token` — случайная часть, уникальная для вашей ссылки.

{% hint style="info" %}
Не меняйте URL вручную и не «собирайте» ссылку сами. Всегда берите её из бота кнопкой **Реферальная ссылка**.
{% endhint %}

## Параметры ссылки

Экран **Параметры** → переключатели **Вкл / Выкл**:

| Параметр | Зачем |
| --- | --- |
| **Встроенный вход** | Форма авторизации внутри страницы |
| **Маскировка** | Скрывает содержимое от лишних проверок |
| **Блок VPN** | Не пускать посетителей с VPN |
| **Случайный адрес** | Генерировать path автоматически |
| **Ошибка при логе** | Показывать ошибку, если лог не прошёл |
| **Ошибка при трейде** | Показывать ошибку при проблеме с обменом |
| **Ошибка MaFile** | Показывать ошибку, если MaFile не принят |
| **Редирект MaFile** | После MaFile отправлять пользователя в Steam |

Нажмите параметр в кнопках, чтобы включить или выключить.

### Окно входа

| Вариант | Смысл |
| --- | --- |
| **Фейк-окно** | Имитация отдельного окна (часто по умолчанию) |
| **Текущее окно** | В том же окне / вкладке |
| **Новое окно** | Открытие в новом окне |
| **About:Blank** | Через about:blank |

## Командный и личный домен — в чём разница

| | Командный | Личный |
| --- | --- | --- |
| Откуда берётся | Даёт команда | Вы добавляете сами |
| Рефералка | Кнопка **Реферальная ссылка** | Нет |
| Создать свою ссылку | Нет (только рефералка) | Кнопка **Создать ссылку** |
| Удалить домен | Нельзя | Можно (**Удалить домен**) |
| Чьи ссылки видны | Только ваши | Ваши на этом домене |

## Свой домен (опционально)

Если нужен личный домен под свои связки:

{% stepper %}
{% step %}
В **Сайтах** нажмите **Добавить домен**.
{% endstep %}

{% step %}
Отправьте домен текстом, например `example.com` (без `https://` и без путей).
{% endstep %}

{% step %}
Дождитесь проверки. Бот покажет **IP** для привязки — пропишите **A-запись** домена на этот IP у регистратора.
{% endstep %}

{% step %}
Подтвердите **Добавить домен**. После успеха откройте домен и при необходимости создайте ссылку.
{% endstep %}
{% endstepper %}

### Создание ссылки на личном домене

1. Откройте свой домен.
2. Нажмите **Создать ссылку**.
3. При желании задайте **Адрес** (path) или оставьте «необязательно» — бот сгенерирует сам.
4. Обязательно выберите **Шаблон**.
5. Выберите **Окно**.
6. Нажмите **Создать ссылку**.

Успех: сообщение **«Ссылка создана»** с путём `/{path}`.

{% hint style="warning" %}
Удалить можно **только свой** домен. Командный домен удалять нельзя — кнопки удаления на нём нет.
{% endhint %}

## Частые вопросы

<details>
<summary>Где взять рефералку для залива?</summary>

**Сайты** → командный домен → **Реферальная ссылка** → скопировать URL из code-блока.
</details>

<details>
<summary>Почему нет кнопки «Реферальная ссылка»?</summary>

Вы открыли **личный** домен. Рефералка есть только на доменах с меткой **командный**.
</details>

<details>
<summary>Можно ли сделать вторую рефералку на том же домене?</summary>

Нет. На командном домене у вас одна реферальная ссылка. Для дополнительных связок используйте **личный** домен и **Создать ссылку**.
</details>

<details>
<summary>Почему статистика пустая?</summary>

Нажмите **Обновить**. Если трафика ещё не было — визиты и остальное будут нулевыми. Убедитесь, что льёте именно URL из бота, без правок.
</details>

<details>
<summary>Нужно ли что-то настраивать перед первым заливом?</summary>

Обычно достаточно получить рефералку. Шаблон и окно уже заданы по умолчанию. Параметры меняйте только если понимаете, зачем — иначе оставьте как есть или спросите куратора / прозвон.
</details>

## Краткая шпаргалка

1. **/start** → **Сайты**
2. Домен с меткой **командный**
3. **Реферальная ссылка**
4. Скопировать URL
5. При необходимости: **Параметры** / **Шаблон** / **Окно входа** / **Обновить**
